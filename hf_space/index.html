Pipeline architecture

SOURCE (hashed .md/.txt, EN or AR) → UNDERSTAND (local Falcon-H1-7B via Ollama: grounded concept extraction, deterministic source-span verification) → STRUCTURE (Episode Builder: verified concepts → short educational sentences) → SIGN PLAN (semantic decomposition: meaning, not just key_terms) → TERMINOLOGY (contextual EN→AR term translation for unresolved items, only when the source is English) → SIGN RESOLUTION (deterministic match against the 1,143-entry ZHO catalog, or Arabic-fingerspelling fallback — NO model involved) → VALIDATE (deterministic provenance/coverage checks; can BLOCK rendering) → CLIP PREP (download + auto-trim ZHO clips, cached) → MEDIAPIPE + RENDER (procedural avatar renderer) → TRACEABILITY (every rendered segment traced back to its source span)
Every stage writes a JSON artifact — nothing generated downstream is ever treated as a new fact. The original source file is the sole authority throughout.
